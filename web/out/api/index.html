NAiERM SiteGround API

This static SiteGround build uses PHP endpoints backed by the bundled SQL schema.

The old Next.js API routes are parked. The active SiteGround-compatible endpoints are PHP files under /api/.

Active Endpoints

  • POST /api/submit-simulation.php - stores a public simulator submission
  • POST /api/submit-feedback.php - stores feedback and optional contact details
  • GET /api/leaderboard.php - returns public submission rows for the leaderboard

Database Setup

Import the MySQL schema from siteground/mysql/naierm_mysql_schema.sql, then place your database credentials in /siteground-config/database.php one level above public_html.

Current Scope

  • Public simulator submissions are active again.
  • Feedback storage is active again.
  • Leaderboard reads are active again.
  • Survey submissions now flow through the public SQL bridge.
  • Admin remains parked in this first SQL pass.
