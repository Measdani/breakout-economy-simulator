Benefit Structure

BEL and Supplemental Support

This section captures the current consumer-liquidity design, including the adult BEL floor, child tiers, and breakout dynamics.

BEL per adult

$12,000

Annual baseline allocation for each modeled adult.

Dependent tiers

$6,000 / $4,000 / $2,000

Tiered dependent support for first, second, and third dependents.

Supplement peak

$6,000

Maximum supplemental support centered around $24,000 before phasing out.

Breakout threshold

$60,000

Above this income level, supplemental support phases to zero and BEL remains the standing floor.

Program Modules

Retirement and Healthcare

These modules can materially change fiscal balance, so they are documented separately from the BEL core.

Retirement program

Disabled

The current scenario leaves retirement modeling off and benchmarks only against baseline expectations.

Retirement payout basis

Final 3-year average

80% replacement rate, 70% actuarial adjustment, salary cap $250,000.

Healthcare module

Baseline federal spend

Federal healthcare baseline: $1.91T. Efficiency levers are currently set to 0% AI diagnostics, 0% admin automation, and 0% transparency savings.

Social Security baseline

$1.30T

Used as the current federal retirement benchmark for scenario comparison.
